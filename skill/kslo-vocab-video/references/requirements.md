# Requirements (the user's standing rules)

Every rule below was stated or approved by the user (K S Lo English teacher) while producing the S2 Unit 1 video
(versions V1-V5), plus the cost-saving format v2 agreed on 2026-10-17 (tag [F]). Treat them as fixed requirements for
every new unit. The tag in brackets is where it came from. Where format v2 changed an older rule, the older rule is marked.

## Voice and pronunciation (details in `voice_and_audio.md`)

| # | Requirement |
|---|---|
| V1 | Miss K's voice must sound **young and natural, slightly anime but not exaggerated**. The user chose studio voice **Leda**, en-GB, with **no pitch lift** ("A: natural"). The teacher loves this familiar voice and explicitly chose **particular-word British pronunciation corrections while keeping Leda**, not a different native British voice. Do not switch voice models without explicit approval; preserve naturalness where a pronunciation correction is unreliable. [V1 fix 3; 2026-10-18] |
| V2 | **"K S Lo"**: "Lo" sounds like **"low"**, never "law". Write "K S Low" in TTS text. [V1 note] |
| V3 | Every word and phrase ends with a **falling (statement) tone, never a rising question-like tone**. Check every take. [V2 fix 5] |
| V4 | Pronunciation must be natural and fully voiced. 'haggle' came out creaky ("weird") and was re-recorded. [V2 fix 3] |
| V5 | **Every word in a phrase is clear**, including short function words. In 'a variety of', the "of" was too short and unclear. [V3 fix 2] |
| V6 | **All items sound equally loud** ('unique' sounded quieter). [V3 fix 1] |
| V7 | Long lines have **no stray sounds** (an extra "s" after "K S Lo students") and **no unclear passages** (05:02-05:04 was smeared). [V2 fixes 6-7] |
| V8 | Miss K says the full phrase, including a leading article ("a variety of"). [V1 note 8] |
| V9 | **Verify actual stress and unvoiced final consonants by listening**, not ASR spelling/pitch alone: concern has second-syllable stress; boost retains audible final /t/ without an extra vowel. Preserve consonant guards through preparation and final music/SFX. For named repairs change only named takes and preserve approved images/other audio. [Unit 3, 2026-10-19] |

## Format v2: lower production cost (agreed 2026-10-17)

| # | Requirement |
|---|---|
| F1 | **No per-item Miss K clips.** Generating 30 lip-synced clips per unit was the main cost. Item answers are voice-only with the badge (S4). |
| F2 | **Reusable, generic Miss K clips** made once and reused for every unit: intro, transition, outro, idle, and six encouragement pop-ups. Their scripts never mention a unit, a number or specific words, so they fit any video. **The unit title appears only as on-screen text.** |
| F3 | **Encouragement pop-ups**: after every 5 items within a part, **only if at least three words/phrases remain in that same part**, Miss K slides in from the right with a short line ("Great job! Keep going!") in a speech bubble with an "N of TOTAL done" progress bar, then slides out (about 4-5 s). Do not count items in the next part; never isolate the final one or two items before a transition or outro. For Unit 2, pop-ups follow global items **5, 10, 21 and 26**, not 15. Lines `pop1`-`pop5` rotate; `pop6` ("Almost there!") is kept for the last permitted pop-up. [minimum-three update, 2026-10-18] |
| F4 | The library lives in **ksloenglish/kslo-vocab-video**, made **PUBLIC at the owner's request on2026-10-19**, with character images, brand logo, vocabulary DOCX and Unit 1 reference. Colleagues can clone/download anonymously; GitHub integration is optional for reading public assets. Fetch with `scripts/fetch_assets.sh`; see sharing_and_access.md. |
| F5 | **Do not regenerate library clips for a normal unit.** Regenerate one only if the user asks or it fails QA, and then update the repo (new clip, `library.json`, `stab.json`). The gesture rule M4 applies to library clips too (intro wave on "Hello"; outro wave only on "See you next time"). |
| F6 | Unit 1 (V5) stays as delivered; the new format starts with Unit 2. |
| F7 | **Never clip speech-bubble words.** Fit both headline and subtitle using actual glyph bounds inside padded safe rectangles; preserve all wording and punctuation. Auto-reduce font size only to readable floors, then stop with an error rather than truncate, hide, or crop. Run `check_popup_layout.py` on **all six** library lines, including unused ones, and inspect every used pop-up at entry, maximum-scale overshoot, hold and exit. Recheck every pop-up in the encoded final video. [Unit 2 clipping fix, 2026-10-18] |
